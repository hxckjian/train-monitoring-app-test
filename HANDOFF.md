```bash
python -m ipykernel install --user --name nebula-ps3 --display-name "Python (nebula-ps3)"

# 3. verify everything still works
python -m pytest tests/ -q
python -m subsystems.door.train

```

If all three commands pass, the project is fully restored.

## The rules this project runs on

These are not style preferences. Two of them are **scored** by the judges
(specification Section 3.2: *"a high score achieved through a leaky split will
not score well"*).

1. **Tests before models.** Every number comes from `scoring/metrics.py` and is
   checked in `tests/`. A number not produced by that code does not go on a
   slide.
2. **Leakage discipline, per subsystem.** Door = contiguous time blocks.
   Rail = stratified repeated CV grouped by file. ACV = leave-one-case-out.
   SHM = fatigue constants fitted in-fold only.
3. **Pre-register.** Fix the measure, the split and the success criteria before
   computing a score. Report a null result as null.
4. **Never type a number.** Everything regenerates from data.
5. **Parse by column name.** Explicit timestamp formats. No positional indexing.
   ACV genuinely scrambles column order *and* renames parameters between files.

## What a new session should NOT redo

These cost real time and are already settled. Check `PROJECT-STATE.md` before
re-deriving any of them.

- All four scoring formulas are **officially disclosed** with worked examples in
  the Info Kits. Do not guess them. Do not re-derive them.
- Door segmentation is **solved**: rows exist only during cycles, any gap
  threshold from 0.05 s to 5 s recovers exactly the right segments.
- The SHM labels were generated by rainflow counting + Miner's rule — the Info
  Kit says so outright. Fitting the two S-N constants is fitting the actual
  generating process.
- `predict.py` is **not** a compulsory deliverable. The Info Kits say it is;
  specification Section 4.1 supersedes them. Compulsory = video, predictions.zip,
  app.
- The Rail Info Kit contradicts itself on class counts (§2.2 vs §4). The data
  wins: 234 Normal / 14 Side I / 24 Side II.
