# Subsystem

- **Name:** SHM — structural health monitoring, cumulative fatigue damage
- **Automatically chosen slug:** `shm`
- **Owner:** _to be filled in by the team member_

# Task

Predict one cumulative fatigue-damage value per dynamic-stress file. Regression,
one row per file. Under Miner's rule, D = 1 is the end of fatigue life.

# Input

- `.csv`, one or more files per call.
- **No header, exactly one column** of stress values (training files: 581,120
  samples each). A file with a header row is rejected with a message saying so.
- The file name becomes `file_id` and must be unique within one call.

# Data processing

- **Rainflow counting** (ASTM E1049, `rainflow` package) on the **full** series.
  Never decimate: `x[::2]` was measured to drop ~50% of cycles and bias damage
  sums by a file-dependent 5–16%.
- **Damage:** `D = (1/C) · Σ nᵢ · rangeᵢᵐ`. Ranges are used directly; the
  amplitude convention (range/2) only rescales C.
- Evidence for the app: cycles and damage share by stress range, share of damage
  from the largest 0.1% of cycles, min/max stress envelope.

# Validation

- **Split:** 5-fold over files, seed 20260918. m and C fitted **inside each fold only**.
- **Metric:** `max(0, 1 − MAPE)` — `scoring/metrics.py`, SHM_Info_Kit.md §4.
- **Score: 0.9729 ± 0.0067.** With m pinned at exactly 5.0: 0.9729 ± 0.0057.
- m across folds 5.010–5.030. Constant-median baseline 0.0849; a RandomForest on
  summary statistics, same folds, scored 0.732 ± 0.074.

Log C is fitted as the mean log residual, which minimises squared **log** error —
the analogue of the **relative** error MAPE measures. Least squares on raw damage
would chase the large files and wreck the small ones.

# Model

Two scalars: **m = 5.030**, log C = 1.0637 (with a reference range, see artifacts).
m ≈ 5 is the standard S-N exponent for welded steel (EN 1993-1-9 / IIW), which is
strong evidence the labels were generated by this exact method.

# Known limitations

1. Validated against training labels only. If held-out files come from a
   different line or load condition (AW0 vs AW4), the constants could shift; a
   per-condition fit is worth trying if that grouping becomes recoverable.
2. No mean-stress correction. The near-perfect fit suggests the labels used none
   either, but that is inference, not documentation.
3. Two test files predict ≥ 0.5 and one ≥ 0.8 — within the training range
   (0.029–0.928). Nothing is extrapolated past it.
